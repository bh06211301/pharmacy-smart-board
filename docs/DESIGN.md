# SmartRoute 規劃流程 v2：設計規範

> 搭配 `design-tokens.css` 與 `docs/SPEC.md` 使用
> 來源：Claude Design 畫布 A0～A10 線框，視覺直接採用線框現有樣式
> 最後更新：2026-10-25

---

## 0. 給 Claude Code 的原則

1. 所有顏色、字級、間距、圓角都用 `design-tokens.css` 的變數，**不要在頁面裡寫色碼**。
2. 線框裡的灰色長條（代表文字）和虛線框（「路線地圖」「拜訪前簡報」）是佔位，實作時換成真實內容。
3. 圖示用線條圖示（建議 Lucide，`stroke-width: 2`），**不用 emoji**。現有頁面的 emoji 在新版一律移除。
4. 互動元素用真正的 `<button>`、`<a href>`、`<input>`，icon-only 按鈕要加 `aria-label`。
5. 可點的東西高度至少 44px（卡片內的小按鈕例外，32px）。

---

## 1. 整體風格

一句話：**白底、深灰字、藍色只用在「可以按」和「現在選中」，紅色只用在「需要處理」。**

- 層級靠字重和留白分，不靠顏色。標題 700、內文 400，中間用 500。
- 面板用細框線（`--sr-line`）分隔，不加陰影。唯一有陰影感的是浮在地圖上的元件。
- 數字一律等寬（`tabular-nums`），時間、金額、天數才會對齊。
- 狀態一定同時用顏色**和**文字表示（例如紅字「23 天」旁邊寫「逾期」），不能只靠顏色。

### 顏色怎麼用

| 用途 | 變數 | 範例 |
|---|---|---|
| 主要動作、連結、選中 | `--sr-primary` | 「確定，送到手機」、主選單選中底線、今天外框、路線 |
| 需要處理 | `--sr-danger` | 逾期天數、規則衝突、卡住的新店紅框 |
| 數字徽章 | `--sr-danger-strong` 底、白字 | 主選單「客戶 46」 |
| 深色標籤 | `--sr-ink` 底、白字 | 錨點類型「送貨」、選中的篩選膠囊、步驟數字 |
| 次要區塊 | `--sr-bg-subtle` | A1 第 1 欄、側欄、表頭 |

## 2. 元件

### 2.1 主選單

- 高度 `--sr-nav-h`（56px），白底，下方 1px `--sr-line`。
- 左：「SmartRoute」15px 粗體。
- 主要分頁：今天、本週、本月、客戶、新店開發，15px。
- 分隔線（1px × 22px，`--sr-line`），後面接「管理」（12px `--sr-ink-3`）與店家規則、待追蹤，13px。
- 未選中：`--sr-ink-2`、400。選中：`--sr-ink`、700、底部 3px `--sr-primary`。
- 徽章：高 18px、膠囊形、`--sr-danger-strong` 底、白字 11px 粗體；數字為 0 時不顯示。
- 右：規劃日（32px 高、細框、13px），找藥局搜尋框（200 × 36px、`--sr-bg-subtle` 底、細框）。

### 2.2 頁首列

主選單下方，各頁自己的工具列。內距 14px 24px，下方 1px 框線。
- A1：‹ 日期 ›（20px 粗體）、假日標籤、天氣、出發與收工地點、清單／地圖切換、預估收工時間（26px 粗體，超過 17:30 變 `--sr-danger`）。

### 2.3 按鈕

| 種類 | 樣式 | 用在 |
|---|---|---|
| 主要 | `--sr-primary` 底、白字、700、高 48px | 每頁最多一個：「確定，送到手機外勤模式」 |
| 一般主要 | `--sr-primary` 底、白字、高 44px | 「加入」「加入今天：一定要去」 |
| 深色 | `--sr-ink` 底、白字 | 對話框的確認動作：「例外加入今天」 |
| 次要 | 白底、1px `--sr-ink` 框 | 「加入今天：順路」「選這個」 |
| 第三 | 白底、1px `--sr-line` 框 | 「延後」「打電話」「先不排」 |
| 文字連結 | `--sr-primary` 文字 | 「開週曆」「看全部紀錄」 |

圓角 `--sr-radius-md`。hover：主要按鈕換 `--sr-primary-hover`；框線按鈕底色換 `--sr-bg-subtle`。

### 2.4 篩選膠囊

高約 24px、12px 字、膠囊圓角。選中：`--sr-ink` 底白字；未選中：白底 1px `--sr-line`。
例：「錨點 2 公里內」「全部」「陌生開發」。

### 2.5 切換鈕（清單／地圖）

兩格連在一起，外框 1px `--sr-ink`、圓角 6px。選中格 `--sr-ink` 底白字粗體，未選中白底。

### 2.6 步驟標題

26px 深色圓形數字 + 16px 粗體標題，例「① 今天一定要去」。只用在 A1 三欄，因為它們真的是順序。

### 2.7 錨點卡（A1 第 1 欄）

白底、1px `--sr-line`、圓角 6px、內距 12px 14px。
- 第一行：店名 15px 粗體，右邊類型標籤（`--sr-ink` 底白字 12px，圓角 4px）。
- 第二行：內容 13px `--sr-ink-2`。
- 第三行：來源 12px `--sr-ink-3`（老爸、待追蹤、約好）。

### 2.8 推薦列（A1 第 2 欄）

三欄格線：勾選框 24px｜內容｜倍數與待追蹤條 120px。
- 店名 15px 粗體、底線連結（點開抽屜），旁邊 12px 距離說明。
- 推薦理由 13px `--sr-ink-2`，格式固定：「階段　天數 / 建議天數 = 倍數，待追蹤摘要」。
- 規則：12px 粗體 `--sr-danger`，「規則：週一不拜訪」。
- 兩條細條（高 6px，底 `--sr-bg-track`，值 `--sr-ink`）：倍數、待追蹤。

狀態：
| 狀態 | 框線 | 底色 | 其他 |
|---|---|---|---|
| 未選 | 1px `--sr-line` | 白 | |
| 已選 | 1px `--sr-ink` | `--sr-bg-selected` | 勾選框填滿 |
| 規則擋住 | 1px 虛線 `--sr-danger` | 白 | 整列透明度 0.55 |

### 2.9 路線清單（A1 第 3 欄）

每列：時間（13px `--sr-ink-2`，44px 寬）｜店名（錨點粗體）｜標籤（11px，細框）。列與列之間 1px `--sr-line-row`。
底部：總站數、公里數、車程。

### 2.10 兩週小日曆

7 欄格線、間距 3px。每格高 40px、圓角 4px：日期 12px、下方 9px 件數、最底 4px 週期色帶（請款期 `--sr-ink`、寄單期 `--sr-line-dashed`）。
今天：內框 2px `--sr-primary`。禁止日（選中店家的）：`--sr-bg-muted`。

### 2.11 面板與區塊

- 欄與欄之間：1px `--sr-line` 直線。
- 區塊內容：內距 20px，區塊之間間距 12px。
- 次要區塊（虛線框）：1px 虛線 `--sr-line-dashed`，用在「系統建議，要加嗎？」「可以拖進來」。

### 2.12 藥局檔案抽屜（A8）

- 從右側滑入，寬 `--sr-drawer-w`（840px），左邊 2px `--sr-ink` 線。後方頁面保留、不變暗太多。
- 頂部：店名 26px 粗體 + 階段標籤；店家代號、區域、藥師 13px；四個動作按鈕。
- 內容依序：為什麼推薦（三格數字）、待追蹤、店家規則、拜訪前簡報、拜訪紀錄、進貨、漏斗歷程。
- 關閉：右上 × 按鈕、按 Esc、點後方頁面。關閉後回到原捲動位置。

### 2.13 規則衝突對話框（A4）

- 寬 `--sr-dialog-w`（620px）、圓角 12px、2px `--sr-ink` 框，後方蓋一層 25% 深色。
- 頂部：12px 粗體紅字「違反店家規則」、24px 標題、規則來源。
- 選項列：白底細框卡片，右邊次要按鈕「選這個」。
- 例外加入：必須填原因的輸入框。
- 底部：「先不排」（第三按鈕）、「例外加入今天」（深色按鈕）。
- 自動調整類規則不用對話框，用右下角提示卡（白底 1px `--sr-ink` 框）＋「好」「復原」。

### 2.14 倍數格（A7 客戶總覽）

格子最小寬 58px、高 50px、間距 4px、圓角 4px。底色依 `--sr-ratio-1`～`--sr-ratio-4`，1.5 倍以上白字。
格內：店名 12px 粗體、倍數 11px（例「1.3×」）。開發中左上角小標「發／初／二／試」。今天已排：外框 3px `--sr-primary`。

### 2.15 漏斗卡（A10）

白底、1px `--sr-line`、圓角 6px。超過建議間隔：改 2px `--sr-danger` 框，倍數紅字。
內容：店名（底線連結）、倍數、區域與天數、「下一步：…」、兩個 28px 小按鈕「排進某天」「記結果」。

### 2.16 地圖（A9）

- 店家點 14px 圓，顏色依倍數分級；開發中空心圓（白底 2px `--sr-ink` 框）。
- 錨點 28px 深色圓、白色站號；補的站 28px `--sr-primary` 圓。
- 錨點範圍：2px 虛線 `--sr-primary` 圓、極淡藍底。
- 路線：4px `--sr-primary` 線。
- 浮動面板與小卡：白底、1px `--sr-ink` 框、圓角 8～10px。

### 2.17 週曆格（A5）

每天一欄：日期 18px 粗體、星期 13px；假日標籤（細框）；天氣小卡（`--sr-bg-subtle` 底，降雨 60% 以上 `--sr-danger` 粗體）；「這天跑哪區」虛線框；「規劃這天的店」連結；指定事項卡；提示文字（上方虛線分隔）。
頂部週期色帶高 26px：請款期 `--sr-ink` 底白字，寄單期 `--sr-line-dashed` 底白字。

### 2.18 月曆格（A6）

格高 108px、圓角 8px、間距 6px。過去的日子依拜訪量 `--sr-load-*` 上色；休息與假日 `--sr-bg-subtle`；今天內框 2px `--sr-primary`；未來白底細框，寫預計區域。底部 5px 週期色帶（請款 `--sr-primary`、寄單 `--sr-primary-soft`）。

## 3. 文字寫法

- 用動詞開頭的按鈕文字，說清楚按了會怎樣：「確定，送到手機外勤模式」，不寫「送出」。
- 同一個動作從頭到尾同一個名稱：按鈕叫「加入今天」，提示就寫「已加入今天」。
- 推薦理由寫計算過程，不寫形容詞：「23 / 21 天 = 1.1 倍」，不寫「很久沒去」。
- 空畫面告訴我下一步：「還沒有錨點，先輸入今天一定要去的店」。
- 錯誤直接說發生什麼、怎麼修，不道歉。

## 4. 響應式（手機版另外設計）

- 1280px 以上：A1 三欄並排。
- 768～1280px：三欄允許換行，第 3 欄掉到下方。
- 768px 以下：全部堆疊成一欄、抽屜改為全螢幕，不能水平捲動。正式的手機外勤模式之後另外設計，沿用同一份 `design-tokens.css`。
