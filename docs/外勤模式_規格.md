## 畫面

### 1 今日行程（首頁）
- 頂部：日期、同步狀態膠囊（已同步 HH:MM／沒訊號 · 待上傳 N 筆／上傳中…）、進度「N / 總數 站完成」＋進度條、預估收工。
- 「下一站」大卡：第幾站、預計到達、店名、地址、車程、分級與警示標籤、拜訪目的、目的備註；按鈕「開始導航」（Google Maps 單點導航）、「我到了」。
- 全部站點清單：完成＝灰圈打勾＋刪除線＋完成時間與摘要；目前站＝藍底；跳過＝灰底「跳過：原因」；未到＝空心圈數字。
- **H 在店時段提醒**：店家規則「在店時段」與預計到達衝突時，該列紅字「藥師 16:00 後才在，會早到 6 分」。
- 清單底部「＋ 臨時加一站」。
- 底部選單：今日／地圖／收工。

### 1a 臨時加一站（A）
- 搜尋店名（正式客戶＋開發中新店），結果顯示行政區、離目前站距離、倍數。
- 去做什麼：拜訪目的（同今日清單選項，可複選）。
- 插在哪裡：最順路的位置（系統算）／馬上去（下一站）／最後一站，每個選項顯示收工時間變化（用 Routes API 固定順序重算）。
- 加入後寫進今日行程（新列），電腦今天頁同步看到。

### 2 到店
- 第幾站、已到時間、打電話按鈕（有電話才出現）。
- 店名、代號、行政區、藥師；分級、警示、天數與倍數。
- 這站要做的事：拜訪目的、目的備註、寄賣金額／月均。
- 上次拜訪 2 筆、待追蹤與規則、「AI 拜訪前簡報」（沿用藥局檔案的產生話術）。
- 底部：「跳過」→ 4；「完成並記錄」→ 正式客戶到 3、新店到 3b。

### 3 記錄拜訪（正式客戶）
- 拜訪類型單選：送貨／巡視／收款／新案開發（與 visit-app 相同）。依拜訪目的預選：送貨→送貨、對帳請款→收款、新店開發→新案開發、其他→巡視。
- **D 實收金額**：類型為收款時出現，顯示應收（寄賣待整理金額），輸入實收。寫入拜訪紀錄表新欄位「實收金額」（只能新增欄位；盤點時確認表上是否已有可用欄位）。老爸負責的店，收工摘要提醒「這筆要交給老爸」。
- 拜訪內容（textarea＋語音按鈕）、標籤（競品／缺貨／客訴／價格／滿意／其他，複選）、緊急問題、下次要記得；勾「同時建立待追蹤（下次經過）」→ 用 addFollowup 建立（已有防重複）。
- **F 照片**：拍照或選相簿，壓縮到長邊 1600px、JPEG，上傳到 Worker 的 R2（PRODUCT_PHOTOS 或新 bucket，盤點時提案），拜訪紀錄存照片網址（新增欄位「照片」，多張用逗號）。
- 舊 field.html 的規則保留：內容含送貨／帳單等字眼且是老爸的店 → 建立「還帳單給爸爸」提醒；收款 → 「錢交給老爸」提醒。
- 儲存：寫拜訪紀錄＋今日行程該站狀態改「完成」，回首頁並把下一站設為目前站。

### 3b 記錄拜訪（新店，B）
- 頂部顯示目前階段與天數。
- 「這次結果」單選：談過了，往下一步（推到下一階段，二訪後之後不提供這個選項）／藥師不在，下次再來（階段不動）／成交轉正式客戶（附代號搜尋，見下方 confirmed 規則）／放棄這家（再選原因：門前藥局、連鎖藥局、名單有誤、藥師沒興趣、其他）。（2026-11-10 field-v2 階段1：拿掉「試賣中」階段，二訪後之後只能選「成交轉正式客戶」或「放棄這家」。）
- 拜訪類型固定「新案開發」；內容＋語音、下次要記得、照片。
- 儲存＝寫拜訪紀錄＋更新新店階段（同新店開發頁「記結果」）＋今日行程狀態「完成」。

### 4 跳過這站
- 原因單選：藥師不在／店休沒開／時間不夠／老爸臨時要我送貨／其他。
- 改哪天：列 2 個建議日期（同區且已排該區的日子優先、其次最近還沒排區的平日）＋選其他日期＋先不排。**只列選項，不預選。**
- 選了日期 → 用 addFollowup 建「拜訪：店名」指定日期（已有防重複＋改期）。
- 今日行程該站狀態「跳過」，原因寫進備註。確定後到 4a。

### 4a 順路補一家（C）
- 底部彈出：「多出 N 分鐘，順路補一家？」列出離目前位置／下一站 2 公里內、倍數 ≥ 1、沒被規則擋、今天不在清單的店，最多 3 家；每家顯示倍數、警示、距離、多花幾分鐘、「加入」。
- 加入＝同 1a 插在最順路的位置。「不用，直接去下一站」關閉。
- 提早完成（實際時間比預估早 20 分鐘以上）時也出現。

### 5 今天收工
- 收工時間、比預估早／晚幾分。
- 統計：完成、跳過、實收金額合計。
- 已自動寫進系統：拜訪紀錄 N 筆、新增待追蹤 N 筆、新店推進／放棄清單。
- 還要處理：跳過但還沒選改期的店，給日期選項按鈕。
- 老爸的事：帳單要還、錢要交的清單。
- 「確認收工」。

## E 沒訊號也能記
- 所有寫入（拜訪紀錄、狀態、待追蹤、新店階段、照片）先進本機佇列（IndexedDB，照片也存本機），有網路就依序送出，失敗自動重試；每筆帶唯一 clientId，伺服器端用它防重複寫入（重送不會多一筆）。
- 頂部膠囊顯示「待上傳 N 筆」；收工畫面若還有未上傳，紅字提醒不要清除瀏覽器資料。
- 讀取：最後一次成功載入的今日行程與店家資料存本機，離線時照樣能開。
