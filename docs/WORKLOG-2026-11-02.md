## 4. 窄螢幕（約640px）主選單問題 ✅ 已上線

**分支**：`fix/narrow-nav-overflow`（已 push 遠端備份，已合併回 main）

**改了什麼**：`planner.html`／`store-rules.html`／`followups.html`／`funnel.html` 四個頁面（各自獨立 `<style>`，沒有共用 CSS 檔，所以四處都要改）：
- `.nav-tabs` 加 `overflow-x: auto; min-width: 0;`，分頁塞不下時自己橫向捲動。
- `.nav-tab`／`.nav-divider`／`.nav-manage-label`／`.nav-brand`／`.nav-right` 都加 `flex-shrink: 0`，`.nav-tab` 額外加 `white-space: nowrap`——原本窄螢幕會把中文標籤擠到逐字換行、疊成一團直排文字，現在改成整個 tab 不換行，塞不下就被捲動區收起來。
- `body` 加 `overflow-x: hidden` 當最後一道保險，不管任何子元素算錯寬度，整頁都不會出現水平捲軸。
- `planner.html` 專屬：700px 以下 `.find-pharmacy-input`（原本固定 200px）縮到 110px，避免跟日期選擇器＋「切回舊版」一起把 `nav-right` 撐太寬。

**測試**：`wrangler dev` + Playwright，640px 寬度下四頁的 `document.body.scrollWidth` 都精確等於 `window.innerWidth`（640，完全沒有水平溢出），`.nav-tabs` 確認是內部可捲動（不是擠爆）；1440px 寬螢幕回歸測試四頁也都沒有變寬、無 console 錯誤。

**部署**：四個檔案都是純前端靜態頁，**沒有動到 `worker.js`，跳過 wrangler deploy**，直接合併 main + push。

**決定記錄**：斷點選 700px（找藥局框縮寬）跟不限斷點（nav-tabs 捲動是任何寬度都開著，寬螢幕下內容塞得下就不會觸發捲動，沒有額外风险，所以沒設 `@media` 包起來）。

**留給你的問題**：無。
